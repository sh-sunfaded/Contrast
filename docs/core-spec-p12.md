## 18. ビューの連続スクロール（P12。niri-complete。17 節の続き）

タッチパッドの 3 本指の横スワイプと、DnD の端スクロールの土台。core はビューの位置を連続量（整数 px）で受け、終わりに列へ吸着させる。
時間（速度・減速）はシェルが扱い、core には「いまの移動量」と「減速して止まるはずの移動量」を渡す。
根拠は niri のソース `src/layout/scrolling.rs`（`view_offset_gesture_begin`・`view_offset_gesture_update`・`view_offset_gesture_end`・
`dnd_scroll_gesture_begin`・`dnd_scroll_gesture_scroll`・`dnd_scroll_gesture_end`）。

- **D85 新しい Command**: `ViewGestureBegin { output: ExternalKey, dnd: bool }`、`ViewGestureUpdate { offset: i32 }`、
  `ViewGestureEnd { projected_offset: i32 }`。`Command` は `#[non_exhaustive]`。
- **D86 開始**: `Scrolling` のとき、出力 `output` の表示中のワークスペースのジェスチャーを始める。そのワークスペースに列が無ければ、
  状態不変で `Ok`（niri も列が無ければ始めない）。開始時の `view_x` を覚える。ほかのワークスペースでジェスチャー中なら、それを先に終える
  （その `view_x` に D39 を当てる）。`Equal` では状態不変で `Ok`。未登録の出力は `UnknownKey`。同時に進むジェスチャーは高々 1 つ。
- **D87 移動**: ジェスチャー中のワークスペースの `view_x` を「開始時の `view_x` + `offset`」にする（`offset` は開始からの合計。正はビューが右へ動く）。
  `dnd` でなければ範囲を制限しない（0 未満や、総幅を超えてもよい）。`dnd` のときは、`view_x` を `[min(−W, R), max(−W, R)]` に収める
  （`W` は作業領域の幅、`R` は最後の列の右端。niri の `dnd_scroll_gesture_scroll` の範囲を絶対位置で書いたもの）。ジェスチャー中でなければ状態不変で `Ok`。
  ジェスチャー中は、そのワークスペースに D39（フォーカス列が見える最小のスクロールとクランプ）を当てない。
- **D88 終了と吸着**: ジェスチャー中でなければ状態不変で `Ok`。`dnd` で、`offset` がずっと 0 だった（最後の Update の `offset` が 0、または Update が無い）ときは、
  ビューを開始時のまま保ち、D39 を当てて終える（niri の「何もスクロールしなかった DnD」）。それ以外は次のとおり（`gaps` は core に無いので 0、作業領域の左端を 0 とする座標）:
  1. 吸着点: 列 `i`（左端 `x_i`、幅 `w_i`）ごとに、左の点 `x_i` と右の点 `x_i + w_i − W`。最も左の点 `L` は列 0 の左の点、最も右の点 `Rs` は最後の列の右の点。
     吸着点の候補は、`L`（列 0）、`Rs`（最後の列）、各列の左の点・右の点のうち `L` より大きく `Rs` より小さいもの（その列）。`L > Rs` でもよい。
  2. 目標 `T` = 開始時の `view_x` + `projected_offset`。候補を位置の昇順に（同じ位置は上の順で）並べ、`|位置 − T|` が最小の最初の候補を選ぶ（位置 `S`、列 `c`）。
  3. 列の選び直し: `T >= 今の view_x` なら、`c + 1` から右へ、`S + W < x_j + w_j` になる列 `j` の手前まで、`c` を `j` にしていく。
     そうでなければ、`c − 1` から左へ、`x_j < S` になる列 `j` の手前まで、`c` を `j` にしていく（niri の「動いた向きに、見えている限り遠い列」）。
  4. `view_x` を `S` にし、列 `c` の「最後にフォーカスした窓」を、そのワークスペースのフォーカスにする（D89）。そのあと D39 を当てる
     （列 `c` が見えるようにし、`view_x` を `0` 以上 `max(0, 総幅 − W)` 以下に収める）。
- **D89 フォーカス**: D88 のフォーカスの変更は、ワークスペースがアクティブな出力に表示されていて、今のフォーカスがそのワークスペースの Tiled の窓か None のときだけ、
  core のフォーカスを移す（`SetFocus`）。それ以外（ほかの出力・浮動の窓にフォーカス）は、そのワークスペースのフォーカス履歴と列の「最後にフォーカスした窓」だけを更新する。
- **D90 ほかの命令との関係**: ジェスチャー中のワークスペースの列が空になったら、ジェスチャーを終える（ビューは D39）。ワークスペースが表示されなくなった・出力が外れたときも終える。
  ほかの命令は、ジェスチャーを止めない（列の追加・削除があっても、`view_x` は開始時の `view_x` + 最後の `offset` のまま）。
- **D91 不変条件**: I11（フォーカス列が D39 を満たす）は、ジェスチャー中のワークスペースには当てない。I14: ジェスチャーは高々 1 つで、表示中のワークスペースにあり、そのワークスペースは列を持つ。
- **D92 niri との差（記録）**: core に `gaps` が無いので、吸着点に隙間（niri の `padding`）を含めない。`center-focused-column` は `never` だけ（作者の設定）。
  niri は吸着のあと、列が 1 本で作業領域より狭いときなどに、ビューを範囲の外（列が右端に寄る）に残すことがあるが、Contrast は D39 のクランプを当てる。
  速度の引き継ぎ（吸着のバネの初速）はシェルの仕事（F の項目）。
